## 分镜与配音

| # | 场景 | 配音 |
| --- | --- | --- |
| 1 | 痛点 | 让 AI 帮你干活，它答应得很爽快，干到一半就跑偏了。 |
| 2 | 类比 | 就像让朋友帮忙搬家，不说搬去哪儿，也不说先搬什么，他只能瞎搬。 |
| 3 | 它做什么 | 先逼它写下要做成什么，再排好先做哪步、后做哪步。 |
| 4 | 拦住 | 没写完，它一步都动不了。 |
| 5 | 演示 | AI 刚想动手，就被拦下。补上目标和步骤，才放行。 |
| 6 | 留有余地 | 该说话时照样能说，派出去的分身也不会被卡住。 |
| 7 | 收尾 | 先想清楚要什么，再动手。搜索 PTC 纪律，就能装上。 |

## 声音

- 配音：`zh-CN-XiaoxiaoNeural`（edge-tts 神经语音，语速 +14%）
- 背景：程序生成的柔和 pad（A 小调，缓慢起伏），音量压到 −18dB 左右
- 混音：配音归一化到 0.9，整体峰值控制，结尾 0.5 秒淡出
- 实测 −19.4dB 平均 / −0.8dB 峰值，无削波

## 重新生成

```sh
python gen_voice2.py     # 逐句合成配音
python build_audio.py    # 配音时间线 + 背景 → soundtrack.wav，输出 timing.json
python build2.py         # 渲染画面 → 混流 → mp4
```

依赖：Pillow、numpy、edge-tts、`imageio_ffmpeg` 自带 ffmpeg 7.1。
